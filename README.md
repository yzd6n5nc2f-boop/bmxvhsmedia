# BMX VHS Media

Production-ready marketing site + lightweight app shell for BMX VHS Media.

## Brand kit

**Core palette**
- Ink (base): `#0b0b0f`
- Ink soft: `#14151d`
- Cream: `#f7f1e6`
- Cream muted: `#d7cfbf`
- Streak green: `#34e27a`
- Streak red: `#ff4e4e`
- Streak yellow: `#ffd465`
- Accent cyan (micro): `#44d9ff`
- Accent pink (micro): `#ff4fd8`

**Typography**
- Headlines: Archivo Narrow (bold condensed, uppercase)
- Body: Inter (clean modern)

**Logo usage**
- Cassette badge mark: circular badge with tri-color streak, used in header.
- Wordmark: “BMX VHS Media” in uppercase, with optional tagline
  (“music • video • memories • AI”).
- Keep the streak motif small and intentional; do not dominate layouts.

Tokens live in `src/theme.js` for future scaling.

## Local development

```bash
npm install
npm run dev
```

## Build for static deployment

```bash
npm run build
npm run preview
```
